
# Inventory Lite

Inventory Lite is a compact inventory management application written in Python.

It keeps track of products stored in a small warehouse, calculates inventory value and creates simple reports. The project is intentionally lightweight while keeping the code organized into reusable modules.

## Highlights

- Product inventory
- Quantity management
- Inventory valuation
- Low-stock detection
- Text report generation
